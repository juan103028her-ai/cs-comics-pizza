# CS Comics Pizza

Un proyecto base para una marca ficticia que combina pizza, cómics y cultura pop.

## 📦 Estructura

- `index.html`: estructura principal de la landing page
- `styles.css`: estilos visuales del sitio
- `script.js`: comportamiento pequeño y dinámico

## ▶️ Cómo usarlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Si quieres, puedes publicar el sitio con GitHub Pages.

## 🧩 Personalización

Puedes cambiar:
- nombre de la marca
- textos del hero y menú
- colores
- fotos o ilustraciones

## 🚀 Deploy en GitHub Pages

1. Ve a la configuración del repositorio.
2. En **Pages**, selecciona la rama `main`.
3. Guarda y espera a que se publique.
